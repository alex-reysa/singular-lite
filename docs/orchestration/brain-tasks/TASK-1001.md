## Objective

Repair the campaign lifecycle canary's consumer-environment leak. This is a
bootstrap prerequisite discovered while dogfooding release 0.21.0, before the
brain campaign can be frozen. Keep the production runner probe configured with
the real consumer policy, but isolate the deterministic cloned fixture's
worker, gate, audit, import and integration from inherited consumer settings.

## Evidence and suggested investigation

The canary passes production-runner-contract, disposable-worktree-bootstrap and
production-runner-live-readonly-probe, then fails with:
`task file not found: /Users/alejandro/Desktop/999. PROJECTS/singular-lite-brain-integration/docs/orchestration/brain-tasks/TASK-9999.md`.
The fixture wrote TASK-9999 under its own docs/orchestration/tasks as intended.
The host exports SINGULAR_TASKS_DIR and SINGULAR_JSON_CONFIG_FILE pointing to
its real campaign configuration. check_fixture_lifecycle currently runs env
with a small override list but retains these and other ambient SINGULAR_*
settings. Reloading the external host JSON also overrides its fixture runner,
target, gate and state settings. This must never invoke a real provider in the
deterministic lifecycle or mutate host paths.

Use a coherent fixture-only environment isolation boundary. Preserve the
necessary ordinary executable PATH and bootstrap Bash selection; deliberately
supply the fixture's root, runtime and own settings after removing inherited
SINGULAR_* configuration/control variables. Keep all existing live probe,
non-mutation, exact-tree, accepted audit, gate and provider assurance assertions.
Do not waive the canary, disable audits, weaken gates or modify the active
frozen runtime. The operator will explicitly create a new runtime snapshot
from the reviewed integrated fix before the campaign starts.

## Acceptance Criteria

- First record a failing regression that exercises the real canary with hostile

  still uses its intended provider contract and policy.
- The original existing canary and campaign-freeze tests continue passing.
- All fixture lifecycle invocations, including import and integration, share
  the isolation boundary; no subprocess rereads the consumer external config.
- A missing or broken real provider still fails the default canary; no waiver
  is added and no result is fabricated.
- Return the required state packet and real red/green log evidence.
